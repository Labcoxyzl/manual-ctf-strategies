# Competition rules for this toolkit

This summary covers the restrictions relevant to the field guide and prewritten helpers. It reflects the organiser's October 2026 tool review and setup guidance; confirm current instructions on the competition machines.

- **Keep challenge data local.** Do not upload challenge files to online services, obtain external assistance or share challenge content outside the team.
- **No generative AI challenge assistance.** Generative AI must not generate solutions, code or scripts, or analyze challenges. Automatically displayed search-result AI summaries are permitted.
- **Prewritten material is allowed.** Physical and electronic notes, personal repositories and scripts created before the competition are allowed. These helpers are prewritten scripts, not additional approved application entries.
- **Use the approved tool and platform.** The inventory contains 39 Windows entries and 161 Kali entries. Windows-list entries are pre-approved and provided on competition PCs; some run in WSL. Kali installation is best effort and does not guarantee working tools. Check versions, locations and remarks in the [approved catalog](../index.html#tools).
- **Understand the highlighted lists.** The workbook identifies 32 Trend Micro proposals and 168 participant requests. These are origin labels, not evidence that an individual installation works. The guide places the proposed set first for preparation.
- **Respect installation restrictions.** The setup PDF permits packages unrelated to generative AI, but the approved-tool workbook additionally forbids adding AI/ML-related libraries or sub-tools to Python, uv and other extensible tools. Do not install PyTorch or another ML framework on competition systems. Unlisted standalone applications require organiser approval; personal commercial software licences are prohibited.
- **Check access and availability.** The competition uses organiser-provided Windows 11 Pro laptops, with a separate Kali environment available. A tool available in one environment is not automatically available in another. Search and technical references are allowed, but external links need internet; competition services require approved networks.

The toolkit's first release runs on Linux/WSL with CPython 3.10 or newer. Native Windows is unsupported, and organiser-machine compatibility must be checked locally. See [setup and manual alternatives](../scripts/README.md#setup). The guide covers all seven categories and 51 prepared task routes; the helpers cover only their explicitly documented operations.
