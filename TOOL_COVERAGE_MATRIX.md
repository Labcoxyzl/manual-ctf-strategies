# Approved-tool coverage matrix

All **200 original workbook rows** are preserved, including platform duplicates and original reference URLs. Priorities are preparation judgments from the announced categories, not organiser mandates or predictions of unseen challenges.

**Essential** = broadly useful capability to prepare; **specialist** = input-triggered method; **alternative** = overlapping implementation worth knowing how to route to; **support** = runtime/editor/helper. A concise command reference plus a concrete check is appropriate for a small utility. No reference-only label implies a large tool is mastered.

“Current video depth” audits the original eight clips only. It is deliberately separate from the expanded instruction. [Full CSV](research/learning/video-coverage/coverage.csv) includes all skills, prerequisites and limitations without table truncation; [catalog](TOOL_RESOURCE_CATALOG.md) gives the selected lesson details.
