## Evidence scope

[Detailed evaluations](research/learning-resources.json) include source URLs and inspected passages for every original selection. Original lane evidence remains under `research/learning/eval-*.json`. A replaced link is preserved in the previous pack and evaluation evidence; no approval row was removed.

The external Wireshark `http.cap` is now a named optional transfer exercise; the core uses a tiny locally authored PCAP with checked answers. Videos are optional alternatives and every one has a free reading route. Capability READMEs for managed-code tools are labeled routing references, not full tutorials.

Link availability is not instructional quality. Source reading supports the stated scope; metadata/transcripts cannot establish video presentation quality, successful playback or learning gains. See [review](research/learning/review.md) and [checks](research/learning/validation.json) for the final state.
